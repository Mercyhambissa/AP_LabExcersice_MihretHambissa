# Java Projects

This repository contains 3 Java projects I developed using Java and JavaFX.

## Projects

### 1. Notepad App
A simple notepad application with a graphical interface.

Features:
- Create new files
- Open files
- Save files
- Edit text
- Cut, copy, and paste

---

### 2. Chat Application
A multi-client chat application using socket programming and JavaFX.

Features:
- Multiple users can chat
- Real-time messaging
- Client-server communication
- GUI interface
- Image sending support

---

### 3. Poker Game
A simple poker-style card game made with JavaFX.

Features:
- Random card generation
- Player vs computer
- Win/lose system
- Interactive GUI

---

## Technologies Used
- Java
- JavaFX
- Socket Programming
- File Handling
- Multithreading
